## 実モデルでのPC検証

固定コミット627aef95638667ddcaa3ac8ae625e88ea5b02f51のモデル467,460,978バイトとCSV308,468バイトを公式配布元から取得しました。モデルは公式LFS情報のSHA256、CSVは配布元Git blobのハッシュと一致しました。

localhostの配信成果物を/wd-tagger-web/配下で開き、ChromiumとWebKitで実モデルを手動選択し、架空の図形画像を解析しました。両方とも448px入力、CSVと出力10,861件が一致し、解析完了しました。モデル初期化を含む実測は約5.0秒と5.5秒です。ダウンロード時間は含めていません。ユーザーの画像は使用していません。

ブラウザから公式配布URLへのCORSを確認し、モデル・CSVともRange GETでHTTP206と読めるレスポンスを取得しました。モデルのRange確認では最初の1KBを読んでストリームを中断するため、Chromiumのネットワーク記録には意図したERR_ABORTEDが1件あります。実モデルの読み込み・解析エラーではありません。モデル全体は別途取得してハッシュを確認しています。

## 明確な検証限界

- 一般的な回帰テストは固定推論結果を使います。別途、上記の実モデルPC解析と実ランタイムの小型モデルテストを実施しました。解析精度、ピークメモリ、iPhoneでの速度・安定性は未検証です。
- WebKitテストはWindows上で実行しており、iPhone Safariの実機テストではありません。
- 翻訳表示修正は、Git管理外の実辞書と公式CSV10,861件を全件比較しました。変更した表示は27件の内蔵訳と3件の略語だけで、元の日本語3,150件は維持しました。両ブラウザで主結果・詳細タグ全件の不一致は0件です。辞書出力の全項目一致も確認しました。
- 修正後の未翻訳扱いは7,659件（オンラインキャッシュなし）。このうち7,610件は英字を含み、49件は記号・年号などです。採用済み略語3件はこの未翻訳数に含めません。訳の意味や全手動確認を保証する集計ではありません。
- 回帰テストは架空の値だけを使います。教師JSON・実辞書の個別検証はGit管理外で実施。衣装の実ファイルは破損疑いにより取り込み不可で、再出力版の往復確認は未実施です。
- MyMemory実通信と翻訳失敗2件の原因は未検証です。エンジンの配信はjsDelivrから同じサイトのランタイムファイルへ変更しました。
- クリップボードのOS権限、iCloud Driveへの保存、ページ終了警告のiOSでの挙動は未検証です。
- GitHub Pagesへの公開とGitHub Actions上の実行は未実施です。配布元CORSとローカルHTTPのMIMEは確認済みで、Pages実環境・オフライン動作は未検証です。

## v18から引き継いでいる既知の課題

教師JSONの個別検証に伴い、保存済み判定の復元・未編集保存・承認状態表示・不要タグの集計を修正しました。以下は次段階へ残っています。

- 翻訳失敗理由が表示されず、繰り返し失敗したタグが再試行対象に残る。
- 一括翻訳の母集団がCSV全タグではない。
- 履歴集計は表示説明と異なり、学習未承認の判定も集計する。
- 衣装の直接編集、途中作業の自動保存・再開、モデル自動取得は未実装。
- 新規解析で35%以上のタグが0件だと、新規教師JSONを生成できない。既存JSONは解析なしで保存可能。

初回のブラウザテストで履歴の表示訳を「ロングヘア」と仮定して2件失敗しました。実際のv18はルール訳「長い髪」を優先するため、既存動作に合わせてテストの期待値を修正しました。アプリの翻訳ロジックは変更していません。

## 次の検証とiPhone実機確認

辞書・衣装の検証結果を報告して停止します。正常な衣装プリセットの再出力版が提供されたら、その実データで検証します。モデル推論・公開・追加機能にはまだ進みません。公開後のiPhone確認は一度に全部を依頼せず、最初は以下の手順から案内します。

1. 提供するHTTPS公開URLをSafariで開く。
2. 指定したモデル・CSVを選択し、個人情報を含まないテスト画像を1枚選ぶ。
3. 「解析を開始」を押し、画面を開いたまま待つ。
4. 解析完了までの時間、最後のログ、Safariが再読み込みされたかを報告する。

この確認が通ってから、タグ判定・教師JSONの「ファイル」への保存・辞書と衣装の移行へ進みます。現時点ではiPhoneの操作は不要です。
